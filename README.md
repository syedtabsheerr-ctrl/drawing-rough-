# RoughSpace

A personal infinite rough notebook for mobile Chrome. The app is static and has no account or cloud sync. Drawings and imported images are saved in local browser storage on the device.

## GitHub Pages

The repository includes a GitHub Actions workflow. After pushing to `main`, open **Actions** and wait for **Deploy RoughSpace to GitHub Pages** to complete. The Pages URL will appear in the workflow deployment summary and under **Settings → Pages**.

Open the HTTPS Pages URL in Android Chrome, then choose **⋮ → Install app** or **Add to Home screen**.

## Data and limitations

- Notes remain in this browser profile; clearing site data can erase them. Use Backup JSON regularly.
- The app supports pen, pencil, marker, eraser, area eraser, hand-pan, pinch zoom, image import, PNG export and JSON backup/restore.
- PDF annotation/import and vector PDF export are not included in this compact hosted build.
- App source is public. Notebook content is not uploaded to GitHub.
